# Canonical rule IDs

Keep the existing dotted IDs in rule files, checker recipes, area bindings and saved references. For example, `vedic.houses.mars-house-7` identifies the Mars placement rule for house seven.

An ID has three segments, `system.topic-key.slug`. Join nested topic path segments with a hyphen. Titles, translations and citation corrections retain their IDs. Distinct formations, schools or reference points receive distinct IDs under the [identifier register](governance/review/identifiers.yaml).
